# 📚 Task Manager 

A simple web-based task manager built using Flask.

## 🚀 Features
- Add tasks
- Mark tasks complete
- Delete tasks
- Persistent storage using JSON

## 🛠 Tech Used
- Python (Flask)
- HTML, CSS
- JSON
